# Programação Orientada a Objetos - UNIFESP

Repositório destinado às atividades e projetos práticos da Unidade Curricular de Programação Orientada a Objetos (POO) da Universidade Federal de São Paulo (UNIFESP).

## Projetos

- **head_tail**: Aplicação Windows Forms simulando o jogo de Cara ou Coroa com animação de sorteio, sprites para Heads e Tails, e lógica encapsulada em classe de domínio.
- **screen_saver**: Aplicação Windows Forms simulando um protetor de tela com movimentação contínua e colisão de elementos gráficos nas bordas da janela com troca dinâmica de sprites.
- **namorar_comigo**: Aplicação Windows Forms interativa com a pergunta "Quer namorar comigo?", botão "Sim" com popup de confirmação e botão "Não" esquivo que foge do cursor do mouse.
- **balistica**: Aplicação Windows Forms simulando o lançamento oblíquo balístico da catapulta Melanpulta com projétil de melancia, aplicando a fórmula do sovetão (MRUV) com gravidade de 9.81 m/s² a partir das velocidades iniciais X e Y.
