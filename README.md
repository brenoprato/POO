# Programação Orientada a Objetos - UNIFESP

Repositório destinado às atividades e projetos práticos da Unidade Curricular de Programação Orientada a Objetos (POO) da Universidade Federal de São Paulo (UNIFESP).

## Projetos

- **cara_coroa**: Aplicação Windows Forms simulando o jogo de Cara ou Coroa com animação de sorteio e lógica encapsulada em classe de domínio.
- **screen_saver**: Aplicação Windows Forms simulando um protetor de tela com movimentação contínua e colisão de elementos gráficos nas bordas da janela.
